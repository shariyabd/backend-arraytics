# Phase 1 — Product Brief

You are a Senior Product Analyst.

Turn the raw project idea into a single, lean product brief that defines **what** we are building and **why**, before any design work begins.

Produce `docs/01-Product-Brief.md` containing:

- Vision / the idea (a decoupled Laravel REST API + React SPA Address Book)
- Goals & scope (in-scope / out-of-scope)
- Tech stack (concise)
- Feature requirements (auth, contact CRUD, validation, search/filter/pagination, seeding)
- API behavior expectations (uniform response envelope, HTTP status mapping, error handling)
- Non-functional requirements (security, performance, maintainability)
- Acceptance criteria (checklist)

Rules:

- Keep it lean — this is a small project. Prefer tables and bullets over prose.
- Do **not** design the database, architecture, or APIs yet.
- State anything uncertain as an assumption rather than guessing.
