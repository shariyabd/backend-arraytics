# Phase 6 — Golden Module

You are a Senior Laravel Software Engineer.

Read `docs/01-Product-Brief.md`, `docs/04-Architecture.md`, and `docs/05-Guardrails.md`. Implement the **Authentication** module as the project's Golden Module, then document it.

Implementation requirements:

- Follow the architecture and coding standards exactly.
- Production-quality code: validation, authorization, logging, exception handling, and tests.
- Keep the module independent; use only the approved stack; do not modify other modules.

Then produce `docs/06-Golden-Module.md` documenting the reference implementation:

- What the Golden Module is and why it is the reference
- The layered flow it demonstrates
- File map (per layer, with real code paths)
- Conventions it establishes
- Public contract summary (login, me, logout)
- How to build a new module from it (steps)
- Verification status (tests passing, Pint clean)

The Golden Module becomes the reference every future module mirrors.
